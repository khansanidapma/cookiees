# Crumb & Co. — Cookies Website

A responsive, elegant and cute cookie-shop landing page using the requested branding:
- Butter Yellow — #F7E7A8
- Nebula — #B8A9D9
- Seashell — #FFF7EF
- Old Copper — #9A6248

## Run
Open `index.html` in a browser. No build step is required.

## GitHub Pages
Upload all files/folders to a GitHub repository, then enable GitHub Pages from the repository settings. The site is fully static.
