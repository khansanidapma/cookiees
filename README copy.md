# Crumb & Co. — Cookies Website (Enhanced)

Versi yang sudah ditingkatkan dari landing page asli menjadi toko cookies interaktif.

## Fitur Baru
- **Welcome Screen** — Tampilan selamat datang saat pertama kali buka (sekali per session)
- **Menu Cookies Interaktif** — Klik card untuk lihat detail, tombol "Tambah ke Keranjang"
- **Keranjang Belanja** — Sidebar cart dengan quantity control, total harga, simpan di localStorage
- **Checkout via WhatsApp** — Langsung buka WhatsApp dengan pesan pesanan
- **Form Pesanan** — Form sederhana yang juga mengarah ke WhatsApp
- **Social Media** — Link Instagram & WhatsApp
- **Testimoni** — Section review pelanggan
- **Mobile Menu** — Hamburger menu untuk layar kecil
- **Harga** — Harga realistis dalam Rupiah

## Cara Pakai
1. Ganti folder `enhanced_cookiees` ini ke dalam repo kamu (atau replace file `index.html`, `style.css`, `script.js`, dan pastikan `assets/cookies.jpg` ada).
2. **PENTING**: Ganti nomor WhatsApp `6281234567890` di `script.js` dan `index.html` dengan nomor WhatsApp kamu sendiri.
3. Upload ke GitHub dan pastikan GitHub Pages aktif.
